# Software Engineering II – Projekt

Dieses Repository enthält ein semesterbegleitendes Projekt im Modul Software Engineering I/II. Ziel ist es, den Softwareentwicklungsprozess strukturiert und praxisnah anhand eines Rollenspiels zwischen Auftraggeber und Auftragnehmer umzusetzen.


## Projektbeschreibung

Im Rahmen des Projekts wird eine kleine Softwarelösung für eine selbst gewählte Domäne entwickelt. Der Fokus liegt dabei nicht auf umfangreicher Implementierung, sondern auf einer systematischen und ingenieurmäßigen Vorgehensweise im Entwicklungsprozess.

Das Projekt umfasst unter anderem:

* Erstellung eines Lastenhefts (Auftraggeber)
* Erstellung eines Pflichtenhefts (Auftragnehmer)
* Planung und Dokumentation des Projekts
* Auswahl einer geeigneten Entwicklungsumgebung
* Modellierung mit UML
* Implementierung eines Prototyps
* Test, Dokumentation und Release

## Ziel

Ziel des Projekts ist es, den vollständigen Softwareentwicklungsprozess von der Anforderungsanalyse bis zum Release und zur Wartung praktisch nachzuvollziehen.

## Erweiterung im aktuellen Meilenstein
Im aktuellen Meilenstein wird die Study-Planner-Anwendung um eine zusätzliche Funktion erweitert. Termine und Lernblöcke können künftig als „erledigt“ oder wieder als „offen“ markiert werden.

Die Erweiterung wird im Pflichtenheft, in den UML-Diagrammen, in der Implementierung, in den Tests und in der Dokumentation nachvollziehbar ergänzt.
